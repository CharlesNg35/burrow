## Reading the results

- **Encrypted, like for like** (burrow default against rathole with Noise): 2.3x the single-stream throughput, 1.8x with 4 streams, 2.3x the new connections per second, lower p99 under load, and 13x less memory with 10k idle connections. rathole's Noise transport (snowstorm) keeps large per-connection buffers, so its memory grows by about 250 KiB per idle connection; burrow allocates buffers only while data flows.
- **AES-GCM** (`cipher: aes-gcm`) adds 77% single-stream throughput over ChaChaPoly on this AES-NI machine, at the same latency and memory.
- **Plaintext against rathole tcp** (both unencrypted): burrow moves 2.1x the data on one stream (1.3x on four) and uses about 40% less memory, but rathole opens about 8% more connections per second (15.3k vs 14.2k). burrow still authenticates every data channel with a full Noise handshake in plaintext mode, so refilling the pool costs more CPU than rathole's token check. This is the one row where burrow does not beat rathole, and it is deliberate: the secret never crosses the wire in clear text.
- **WebSocket transport** (burrow over `ws://` against chisel, which also tunnels over WebSocket): 2x chisel's single-stream throughput and 5.6x with 4 streams, a lower p99 under load, and half the memory with 10k idle connections. Against burrow's own TCP transport it keeps about 93% of the throughput; idle memory nearly doubles because each WebSocket end keeps its own frame buffers.
- **Multiplexing** (frp with and without `tcpMux`, same code): turning multiplexing off raises frp's throughput (8.8 to 36.0 Gbit/s with 4 streams) and lowers its p99 under load (678 to 383 µs), but drops new connections per second from 10.0k to 2.9k, because every visitor then waits for a fresh TLS connection. burrow's pre-opened pool gets channel-per-visitor latency and throughput without paying that setup cost (13.5k connections/s).
- Everything runs on one 10-vCPU machine, so the tunnel competes with iperf3 and the load generator for CPU. The absolute numbers are higher on separate machines; the ratios are what to compare.
